# Terraria Takeover

**Portal 2** × Terraria · visual · idea by the team

Bring Terraria into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped Terraria into a Portal 2 chamber: slimes, King Slime and the Eye of Cthulhu get smashed by blocks flying out of portals.

## Install

Copy this mod's files into a new folder called sigf inside your Portal 2 install, together with the kit's game folder files, then start Portal 2 with -game sigf +sv_cheats 1 +map sp_a2_catapult_intro. Slimes and bosses start coming right away.
